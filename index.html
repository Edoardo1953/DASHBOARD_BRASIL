Configura Sincronizzazione GitHub

Come creare il Token (1 minuto):
  1. Vai su github.com → clicca la tua foto → Settings
  2. In fondo a sinistra: Developer settings
  3. Personal access tokens → Fine-grained tokens
  4. Clicca Generate new token
  5. Nome: Dashboard Brasil  |  Expiration: No expiration
  6. Repository access: Only select repositories → seleziona DASHBOARD_BRASIL
  7. Permissions → Repository permissions → Contents → Read and write
  8. Clicca Generate token e copia il codice che appare

Il token viene salvato solo nel tuo browser (localStorage). Non viene mai inviato a server di terze parti.
